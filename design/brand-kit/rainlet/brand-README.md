# Rainlet brand

Rainlet is the name of the admin product (Mist is its design system). The mark is one drop of water filled to a still level; the wordmark is lowercase and drawn with the same round stroke as the Mist icons, so it never depends on a font.

Open `index.html` for the guidelines (usage, clear space, colour, do and do not).

| File                                                                                                      | Use                                                              |
| --------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------- |
| `rainlet-lockup.svg`                                                                                      | Primary logo: tile and wordmark, for light backgrounds           |
| `rainlet-lockup-dark.svg`                                                                                 | Same on dark backgrounds (white tile, blue drop, white wordmark) |
| `rainlet-lockup-stacked.svg`                                                                              | Square or narrow spaces                                          |
| `rainlet-mark.svg`                                                                                        | App icon tile, 256                                               |
| `rainlet-glyph.svg`                                                                                       | The drop alone, `currentColor`, 24 grid, 2px stroke              |
| `rainlet-wordmark.svg`                                                                                    | The name alone, `currentColor`                                   |
| `favicon.svg`, `favicon-32.png`, `favicon-48.png`, `apple-touch-icon.png`, `icon-192.png`, `icon-512.png` | Browser and device icons                                         |
| `social-card.png`                                                                                         | 1200 x 630 link preview                                          |

Colours: Rainlet blue `#0B63CE`, ink `#1F2A33`, paper `#FFFFFF`, Mist tint `#E8F1FC`, night `#1E2E38`. Smallest sizes: tile 16px, lockup 20px tall, wordmark 12px tall. Do not recolour, stretch, rotate, or place on busy backgrounds.

Typeface: Be Vietnam Pro (SIL OFL) for brand surfaces, token `--f-brand`; the admin interface itself stays on the system font stack. Self host weights 400, 500, 600 (Latin and Vietnamese subset, `font-display: swap`).
