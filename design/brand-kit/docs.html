Data and tables

A sample documentation page in the brand: headings, prose, a callout, code tabs and a table. Use it to judge long-form reading.

Status: a working prototype (0.x). The HTML syntax is still Draft.

A table in one element

The table below reads listPeople from an OpenAPI operation; sorting, search and paging are attributes.

PreviewHTMLOpenAPI
<xo-view get="listPeople">
  <xo-table columns="name,email:E-mail,role" sortable page-size="5"></xo-table>
</xo-view>

Attributes

AttributeMeaning
sortableHeader buttons set the sort query parameter.
filtersA search box per field.
page-sizeShows Previous and Next, which change offset.
