Data and tables

Reads are <xo-view get>. Writes are xo-click and xo-submit. The data layer does the caching, retries, loading and errors.

A table in one element

Sorting, a search box, row selection, bulk actions and paging are attributes. The preview fills the width of the page, so wide tables get the room they need.
