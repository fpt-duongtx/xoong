Install

xoong is not on npm yet. Each version is a GitHub Release with one tarball per package. Until it goes public the repository is private, so you need gh signed in to an account that can read it.

1. Download a release

gh release download v0.0.7 -R fpt-duongtx/xoong -D vendor/xoong

2. Point your package.json at the tarballs

Copy dependencies (what you import) and all overrides from vendor/xoong/consume.json, then run npm install.

{
  "dependencies": { "xoong": "file:./vendor/xoong/xoong-0.0.7.tgz", "@xoong/ui": "file:./vendor/xoong/xoong-ui-0.0.7.tgz" },
  "overrides": { "@xoong/core": "file:./vendor/xoong/xoong-core-0.0.7.tgz" }
}

3. Generate typed operations and run

npx xoong sync openapi.json      # writes .xoong/operations.json and api.d.ts
npx xoong dev                    # dev server with an API proxy
npx xoong build --out dist       # static output for strict CSP hosting

Node 22.12 or newer. Full notes: docs/consuming.md in the repository.
