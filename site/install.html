Install

xoong is not on npm yet. Each version is a GitHub Release with one tarball per package. Until the repository is public you need gh signed in to an account that can read it.

You need Node 22.12 or newer. The libraries themselves have no runtime dependencies; Node is only for the tools (xoong sync, dev, build).

1. Download a release

gh release download v0.0.15 -R fpt-duongtx/xoong -D vendor/xoong

The folder holds one .tgz per package and a consume.json that says what to copy into your project.

2. Point your package.json at the tarballs

Copy dependencies (what you import) and every entry of overrides from consume.json, then run npm install.

{
  "dependencies": {
    "xoong": "file:./vendor/xoong/xoong-0.0.15.tgz",
    "@xoong/ui": "file:./vendor/xoong/xoong-ui-0.0.15.tgz"
  },
  "overrides": {
    "@xoong/core": "file:./vendor/xoong/xoong-core-0.0.15.tgz"
  }
}
npm install

3. Generate typed operations and run

Give xoong sync your OpenAPI document (a file or a URL). It writes .xoong/operations.json, which the data layer reads, and api.d.ts for TypeScript.

npx xoong sync openapi.json      # writes .xoong/operations.json and api.d.ts
npx xoong dev                    # static server with an API proxy
npx xoong build --out dist       # static output for strict-CSP hosting
{
  "port": 5173,
  "proxy": { "/api": "http://localhost:8080" }
}

4. A first screen

Or let xoong new do steps 3 and 4: npx xoong new my-app --spec openapi.json creates a project with a first list screen.

<!doctype html>
<link rel="stylesheet" href="/@xoong/ui/src/xoong.css">
<script type="module" src="main.js"></script>

<xo-view get="listPeople">
  <p xo-if="$loading">Loading…</p>
  <xo-table columns="name,email:E-mail,role" sortable></xo-table>
</xo-view>
import { configure } from '@xoong/data';
import '@xoong/data/view';
import '@xoong/ui';
import operations from '/.xoong/operations.json' with { type: 'json' };

configure({ api: operations, baseUrl: '/api' });

Run npx xoong check index.html to lint the markup against your API; each message says how to fix it.
