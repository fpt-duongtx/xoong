xoong

Build data-driven web pages with HTML, plain CSS and your OpenAPI document. No virtual DOM, no runtime dependencies in the core, no build step needed to try it.

Status: a working prototype (0.0.x). It is not published to npm yet, so installing is done from release files. See Install.

What you write

<xo-view get="listPeople">
  <xo-table columns="name,email,role" sortable></xo-table>
</xo-view>

The table, its loading and error states, the cache and the types come from the OpenAPI document. See it running.

Ideas

  • Standards first: custom elements in the Light DOM, the History API, native <dialog>, Intl.
  • Your API is the contract: xoong sync reads OpenAPI and writes typed operations; forms and tables are drawn from the schemas.
  • Strict CSP ready: xoong build produces static output with no inline code.
  • Made for AI and humans: a short llms.txt, an MCP server, and xoong check that catches mistakes in markup.
