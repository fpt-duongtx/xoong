Styling

xoong ships design tokens as custom properties and the default look of its parts as plain CSS in cascade layers. There is nothing to build and nothing to eject: your own CSS wins without specificity fights.

Tokens

Everything in xoong.css is read from --xo-* properties. Change them on :root for the whole app, or on any element for a region. Move the controls to try it on the sample panel (they set the properties on that panel only).

Layers

The default styles live in three layers, xoong.tokens, xoong.base and xoong.components. Unlayered CSS beats any layered CSS, so a plain rule in your stylesheet overrides the default without !important and without matching its specificity. Light and dark come from light-dark() and color-scheme.

/* your stylesheet: no layer, so it wins */
.xo-table th { text-transform: uppercase; letter-spacing: 0.04em; }
xo-dialog > dialog { max-width: 40rem; }

/* or order the layers yourself */
@layer reset, xoong.tokens, xoong.base, xoong.components, app;

The admin shell

Put class="xo-admin" on the body (or on <xo-router>) with a <header>, a <nav> and a <main>, and you have a header, a sidebar and a content area that folds into one column on a phone.

<body class="xo-admin">
  <header>My admin</header>
  <nav><a href="/people" aria-current="page">People</a></nav>
  <main>...</main>
</body>
