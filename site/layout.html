Layout

Every page needs the same four arrangements: things one under the other, things side by side, equal columns, and a centred page column. xoong.css has them as four elements with a few attributes. They are drawn by CSS alone, in a cascade layer (so your own CSS always wins), and they are not utility classes: four names and a handful of values, all checked by xoong check.

<link rel="stylesheet" href="/@xoong/ui/src/xoong.css">

The four elements

ElementWhat it doesAttributes
<xo-stack>children one under the othergap 0 to 4 (default 3); align start, center or end (default: they fill the width)
<xo-row>children side by side, vertically centredgap 0 to 4 (default 2); wrap; align start, center (default), end, baseline, stretch; justify start (default), center, end, between; a child with grow takes the free space
<xo-grid>equal columnsgap 0 to 4 (default 3); cols 1 to 4 (one column on a phone); without cols, as many columns of at least 16rem as fit
<xo-center>the page column: centred, a readable width, side paddingsize narrow (40rem) or wide (80rem); default 64rem

gap is one scale for all of them: 1 is 0.25rem, 2 is 0.5rem, 3 is 1rem, 4 is 1.5rem (the --xo-space-1 to --xo-space-4 tokens), and 0 is none.

Stack

Children one under the other, with a gap between. They fill the width; align="start" (or center, end) lets them keep their own width, for a button that should not stretch.

One
Two
Three
 
<xo-stack gap="2">
  <div class="panel">One</div>
  <div class="panel">Two</div>
  <div class="panel">Three</div>
</xo-stack>
 
<xo-stack gap="2" align="start">
  <button type="button">Save</button>
  <button type="button">Save and close</button>
</xo-stack>

Row

justify="between" pushes the first child to the start and the last to the end. grow on a child makes it take the rest of the row and lets it shrink below its content, so a search box beside a button still fits on a phone. wrap lets children go on a new line when they do not fit. align is the vertical alignment: baseline for text of different sizes, stretch for equal heights.

Articles 
<xo-row justify="between" wrap>
  <strong>Articles</strong>
  <xo-row gap="1"><input type="search" aria-label="Search" placeholder="Search" grow> <button type="button">New</button></xo-row>
</xo-row>

42

itemsSee all 
<xo-row align="baseline" gap="3">
  <h3>42</h3><span>items</span><a href="#">See all</a>
</xo-row>

Grid

cols fixes the number of equal columns (1 to 4) and falls to one column on a phone, so it never gets three squeezed ones. Without cols the grid fits as many columns as there is room for, each at least --xo-grid-min wide (16rem): a list of cards that needs no breakpoint.

Two
Three
 
<xo-grid cols="3">
  <div class="panel">One</div><div class="panel">Two</div><div class="panel">Three</div>
</xo-grid>

</xo-grid>

Center

The page column: centred, at most 64rem (size="narrow" 40rem for text and forms, size="wide" 80rem), with 1rem of padding at the sides so text never touches the edge of a phone. Change the default with --xo-center-max.

Sign in 
<xo-center size="narrow">
  <xo-stack>
    <strong>Sign in</strong>
    <input type="email" aria-label="Email" placeholder="Email">
    <button type="button">Continue</button>
  </xo-stack>
</xo-center>

A page

<xo-center> around a <xo-stack>, a <xo-row justify="between"> for the title and its actions, and an <xo-grid> for the content.

<body>
  <xo-center>
    <xo-stack gap="4">
      <xo-row justify="between" wrap><h1>Team</h1><button>Invite</button></xo-row>
      <xo-grid>
        <xo-view get="listPeople">
          <article xo-each="items"><h3>{name}</h3><p>{role}</p></article>
        </xo-view>
      </xo-grid>
    </xo-stack>
  </xo-center>
</body>

When you need more

  • Your CSS wins. The layout is in a cascade layer, so a rule of yours needs no !important: xo-row { gap: 12px; } replaces the scale for every row.
  • A sidebar, a hero, a masonry, a sticky header are not here, on purpose: write them with your own CSS and the tokens (var(--xo-space-3), var(--xo-color-border)), or use the admin shell (<body class="xo-admin">) for an application with a header, a navigation and a main area. See Styling.
  • xoong check warns about a value the CSS does not know (<xo-row gap="9">, <xo-grid cols="5">), because the browser would silently use the default. Editors complete the elements and values from the same data.
  • The form-array row of a generated form is .xo-array-row (it was .xo-row before these elements: the name belongs to the layout now).
