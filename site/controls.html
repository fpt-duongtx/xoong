Controls

The controls every admin needs, as custom elements in the Light DOM with plain CSS. @xoong/controls depends only on @xoong/core, so it works with or without the rest.

import '@xoong/controls';   // registers every element; or import one: '@xoong/controls/tabs'
<link rel="stylesheet" href="/@xoong/controls/controls.css">  <!-- optional; one @layer, uses the --xo-* tokens -->

The controls

  • Tabs: the WAI-ARIA tabs pattern, panels that stay in the form.
  • Menu and tooltip: a menu button in the top layer, choice menus, descriptions on hover and focus.
  • Combobox and tags: pick from a list you can filter, or type free tags; both are form controls.
  • Carousel: cards, banners, testimonials, galleries, with the platform's scroll snap.
  • Your own control: a form control built on XoControl.
