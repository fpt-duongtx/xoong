Theme builder

Start from a design language, change the colours, shape, shadow and type, check the contrast, and download theme.css. It is one file of custom properties: load it after xoong and every component follows.

4. Download

Load it after xoong's own styles:

<link rel="stylesheet" href="/@xoong/ui/src/xoong.css">
<link rel="stylesheet" href="/@xoong/controls/controls.css">
<link rel="stylesheet" href="theme.css">

To theme one region only, copy the declarations onto a selector such as .sidebar instead of :root. Derived tokens (focus rings, shadows) are defined in the theme itself, so they follow.
