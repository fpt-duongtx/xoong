Icons

84 rounded icons on a 24px grid, in three weights. One class draws one: <i class="xi xi-edit" aria-hidden="true"></i>. The size follows the text, the colour is currentColor, and nothing in the element is a character a screen reader or a crawler could read.

Use it

Add the stylesheet once and write the class. The whole set is @xoong/icons/icons.css; the Mist stylesheet and each control's own stylesheet already carry the icons they draw.

<link rel="stylesheet" href="/@xoong/icons/icons.css">

<i class="xi xi-edit" aria-hidden="true"></i>             regular
<i class="xi xi-fill xi-edit" aria-hidden="true"></i>      fill
<i class="xi xi-bold xi-edit xi-lg" aria-hidden="true"></i> bold, 1.25em
<i class="xi xi-settings xi-spin" aria-hidden="true"></i>   turning

<button><i class="xi xi-trash" aria-hidden="true"></i> Delete</button>
<button aria-label="Delete"><i class="xi xi-trash" aria-hidden="true"></i></button>
ClassEffect
xiThe box: 1em square, currentColor, aligned to the text.
xi-sm xi-lg xi-xl xi-2x xi-3xSizes, as a multiple of the text size (font-size): 0.875, 1.25, 1.5, 2 and 3 em.
xi-fwA fixed width of 1.25em, so a column of icons lines up.
xi-spinTurns once a second (three seconds when the person asked for reduced motion).
xi-fill xi-boldThe filled drawing, or the same outline with a heavier stroke. An icon without a filled drawing (a plus, an arrow) uses the bold outline for fill.

An icon next to text is decoration: aria-hidden="true". An icon alone in a button needs the button's aria-label (the icon is never the name).

Ship only the icons you use

A set of hundreds should not cost a project hundreds of kilobytes. The xoong-icons command reads your sources, finds the xi- classes (and the old data-ic and var(--ic-…) forms), and writes a stylesheet with just those. The fill and bold weights are added only when xi-fill or xi-bold appear.

npx xoong-icons --scan src --scan index.html --out public/icons.css
npx xoong-icons --scan src --include star,heart     # names built at run time, which a scan cannot see
npx xoong-icons --list                              # every name

The source is SVG

Each icon is one hand-drawn SVG file on a 24px grid with a 1.75 stroke, round caps and joins: packages/icons/src/svg/<name>.svg, and a fill/ drawing where a filled form makes sense. The stylesheet is generated from those files as CSS masks (node tools/build-icons.mjs; a test fails when it drifts), so it needs only img-src data: under a strict Content-Security-Policy, with no inline style or script. The set is drawn for xoong: inspired by the soft, even look of current system icons, not copied from any icon library or from Apple's SF Symbols.

The old <span class="ic" data-ic="edit"> keeps working; new code should use the xi classes.
