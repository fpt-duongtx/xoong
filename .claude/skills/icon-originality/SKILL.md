# Originality

The set is MIT. Everything in it must be drawn for it.

- **SF Symbols (Apple)**: the licence allows use only in apps on Apple platforms and forbids reusing the drawings elsewhere. Never export, trace, convert, approximate point by point, or reproduce an SF Symbol, and never put its name or glyph in the set. The iOS look (round ends, soft corners, even weight, optical balance) is a *style*, free to be inspired by.
- **Other libraries** (Feather, Lucide, Heroicons, Material, Font Awesome, Phosphor, Ionicons, Bootstrap Icons ...): same rule. Their licences differ and some forbid derivatives or require attribution; do not mix their paths in.
- **From memory**: do not write out a famous icon's path data from memory. Start from the metaphor and construct the geometry yourself (grid, circles, rects, arcs, polar coordinates). Two icons of the same object from different sets will look alike when the object is simple (a plus, a chevron, a house); that is fine when the construction is yours and the proportions are this set's.
- **Contributions**: ask where the drawing came from. If it was traced, converted from a font, or generated from another set, reject it. A reference photo or a sketch of the object is fine.
- When asked for "the SF Symbol for X", draw an original concept for the same meaning and say so.
